# 360高さナビ

360度カメラの集合写真で、撮影前に推奨カメラ高さを決める現場用Webアプリ（PWA）です。高さは撮影後に直せないため、条件を選ぶだけで推奨高さ・理由・注意点を出すようにしています。

- アプリ: https://hanaphoto.github.io/navi360/
- アプリ名：360高さナビ（ホーム画面名：高さナビ）
- リポジトリ：hanaphoto/navi360

## なぜ高さだけ直せないか

- 水平方向はリフレームで後から選べます。露出・色は現像で追え、傾きは補正できます
- 高さが変わると、見下ろし／見上げの関係、顔の見え方、天井と床の比率、後列の隠れが全て変わり、後処理では再現できません

## 使い方

1. iPhoneのSafariで公開URLを開き、共有メニューから「ホーム画面に追加」する（PWAとして全画面で起動できます）
2. 撮影条件を選ぶ：目的／並び方／人数／構成／場所（室内・屋外、天井高さは任意入力）、必要なら現場メモを書く
3. 「推奨高さを出す」を押すと、推奨高さ（中心値と許容範囲）、一脚／三脚の目安、理由、注意点チェックリストが表示されます
4. 結果はコピーまたは `.txt` 保存ができます。履歴は新しい順に残り、消去もできます

## 入力と出力

- 入力：目的（顔重視／全体・会場重視／リトルプラネット／空間記録）、並び方（円形／半円1列／2〜3列／着席のみ／立ち自由）、人数、構成（大人のみ／子ども中心／大人＋子ども混在）、場所、天井高さ、現場メモ
- 出力：推奨高さ（cm）、許容範囲、距離の目安、注意点チェックリスト（顔にスティッチラインを通さない、レンズ面を人に正対させない等）、理由
- 計算はルールベースの表引きです。AIは使いません

## 仕様・プライバシー

- PWA構成です。一度オンラインで開けば、Service Worker（キャッシュ名 `navi360-v1`）により圏外でも起動できます
- 外部ライブラリや外部フォントの読み込みはありません。外部送信の仕組みもありません
- 履歴と入力内容は端末のブラウザ内（localStorage）にだけ保存されます。Safari本体とホーム画面アプリでは保存領域が別なので、使い始める場所はホーム画面アプリに統一してください
- iOSは長期間使っていないWebアプリの保存データを自動で消すことがあります。永久保存の前提にはしないでください

## ファイル構成

- `index.html`：アプリ本体（PWA用のManifest読み込み・テーマカラー・Service Worker登録を含む）
- `sw.js`：Service Worker。キャッシュ名は `navi360-v1`
- `manifest.webmanifest`：アプリ名「360高さナビ」／短い名前「高さナビ」／全画面表示／テーマカラー #0b6bcb
- `icon-180.png`／`icon-192.png`／`icon-512.png`／`icon-maskable-512.png`：アイコン（青地に白の「360°」）
- `README.md`：この説明書

READMEはアプリの動作対象ファイルではないため、追加してもPWAのキャッシュ（`sw.js` の対象一覧）を変更する必要はありません。
